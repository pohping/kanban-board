# Kanban Board

A simple Kanban board built with Next.js (monorepo).

## Features

- Kanban board with columns
- Task cards
- Drag and drop cards

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Monorepo (pnpm + Turborepo)

## Getting Started

```bash
# Install dependencies
pnpm install

# Run the development server
pnpm dev
```
